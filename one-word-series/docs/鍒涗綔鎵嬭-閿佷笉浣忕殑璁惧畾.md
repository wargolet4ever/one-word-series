# 我给自己的 AI 连戏工具，写了一条永远不可能满足的规则

做 AI 短片的人都知道连戏有多难：第 1 集的夹克到第 3 集换了颜色，楼梯间长出一扇本来没有的窗。

我的解法是把设定写进文件，而不是留在模型的 context 里。一个叫 `bible.json` 的东西存着"不能变的事实"——每个人物的外貌、每个场景的描述、几条连戏规则——然后每一集每一镜的 prompt 都在本地确定性地拼出来，逐字节相同。模型只决定"发生什么"，不再重新描述"这个人长什么样"。

工具叫[一词成剧 / One-Word Series](https://github.com/wargolet4ever/one-word-series)，MIT。

拍完两集之后，我第一次用视觉模型跑了它的跨集漂移检查。

结果是 7 条 DRIFTED。

然后我干了一件事：**不看判定，去看模型到底写了什么。**

---

## 那张表

工具里每一条差异都带着"哪条设定没守住 / 模型实际看到了什么"。我把 11 个被检查的出现按设定归了个类：

| 锁定的事实 | 被判违反 | 模型实际看到的 |
|---|---|---|
| 挂钟显示 4:10 | **6 次** | 10:52、8:25、8:25、7:35、7:35、10:10 |
| **左**眉上的竖疤 | 4 次 | 右脸颊、额头、额头、**右**眉 |
| **左**袖口撕裂 | 5 次 | 卷起、卷起、卷起、卷起、没破 |
| C2 的红色领针 | 4 次 | 没有、没有、没有、深色纽扣 |
| **只有一个**暖光源 | 3 次 | 窗光+环境光、冷色荧光、窗光+壁灯 |
| **扶手是绿色的** | **0 次** | —— 一次都没被判违反 —— |

最后一行是对照组。

**一个大面积、有颜色、属于建筑本身的事实，八个镜头全部守住了。**

而失败的全是同一类东西：小的、分左右的、要读数的、要计数的。

挂钟那条最离谱。**没有任何视频模型能把表盘画成你指定的时间**——它会画一个看起来合理的钟，指针随便指。所以那条规则注定在那个房间的每一镜、每一集、永远失败。

那条规则是我自己写的。它就在我这个仓库自带的模板里，每个第一次用这个工具的人都会拿到它。

---

## 所以这份报告大部分是工具自己制造的噪音

7 条 DRIFTED 里，真正值得知道的只有一条：

> "Wen wears an olive button-up **shirt** (not a workwear jacket)" —— 出现了两次

橄榄色**工装夹克**变成了橄榄色**衬衫**。这是真的连戏事故，是我花钱买视频该被告知的事。

它被六条我自己捏造的告警埋掉了。

**一份大部分是噪音的报告，等于一份没人会打开第二次的报告。**而它之所以是噪音，不是因为检查得不够好，恰恰是因为检查得太诚实——那些设定确实没守住。它们只是从一开始就不可能守住。

---

## 不是所有能写下来的设定，都是能锁住的设定

这是我从这次里学到的唯一一件事，但它挺重要的：

写圣经的时候，人会下意识追求"具体"。越具体越好锁——这是直觉，而这个直觉是错的。**具体到超过模型的分辨能力，就变成了纯噪音。**

按实测，这五类基本锁不住：

| 类别 | 例子 | 为什么 |
|---|---|---|
| **读数** | 钟表时间、仪表数值、屏幕内容 | 模型画不出你指定的表盘 |
| **文字** | 招牌上的字、门牌号 | 会拼错，会自己编 |
| **左右** | 左眉的疤、右口袋的本子 | 模型不记左右 |
| **微小配件** | 领针、徽章、耳钉 | 只有几个像素，放不稳 |
| **计数 / 排他** | "只有一个光源"、"恰好两把椅子" | 模型不数数，它只是构图 |

而这些锁得住：**大形状、材质、颜色**。绿扶手、钢制防火门、橄榄色工装夹克。

有意思的是，这和"怎么写 prompt"的常见建议几乎是反的。大家都在教你写得更细。但**细节的类型比细节的数量重要得多**——一句"绿色扶手"比五句"左袖口第三颗纽扣"有用。

## 我改了什么

1. **模板里那些不可能的设定全部重写了。** 挂钟改成"暗掉的、玻璃裂了"（这是形状和状态，锁得住）；所有"左/右"去掉；领针换成尺寸更大的特征。
2. **加了一个检查器**（`oneword/lockability.py`），开拍之前扫一遍圣经，把上面五类标出来：

```
· 2 locked fact(s) a generator is unlikely to ever hold, so they will read
  as drift in every episode:
    SER-03 [readable-value]
      The wall clock in Unit 704 always reads 4:10.
      → say the clock is stopped and unlit, not what time it shows
  These are not caught by spending more; they are caught by rewording.
```

最后那句是重点：**这类问题不是多花钱能解决的，是改措辞能解决的。**

3. **写剧本的模型也拿到了同一份清单**，所以从你输入的词生成的圣经也会避开它们。
4. **漂移报告里引用这类设定的差异会被标注**——属实，但不是新闻。
5. **加了个测试**：模板里一旦再出现不可能的设定就挂。

## 还没验证的

我不想把这篇写成一篇"问题已解决"。

- 上面那批素材是在参考图机制**之前**拍的，全程没送过任何定妆照。所以这次证明的是**问题真实存在且可测量**，不是证明我的修复有效。疤在四个镜头里跑到了脸颊、额头和另一边眉毛——参考图机制就是为这个造的，但它本身还没被测过。
- 漂移阈值目前标定在一个合成靶场上。真实素材证明靶场**比现实更松**（一个根本没变过的房间读出了 0.072 和 0.123，而靶场同场景最大才 0.0893）。这个还没重新标定。
- 视觉模型的判定不是确定性的。同一批帧跑两次，有的镜头 DRIFTED 有的 REVIEW。本地像素筛是确定性的（每次都是 0.112），模型不是。一次模型判定不是一个稳定的事实。

这些都写在仓库 README 的「还没做的」里。
